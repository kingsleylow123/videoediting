# videoediting: Reels studio for the phone

Make Reels, TikToks and Shorts from the Claude app on your phone.

1. Claude app → Code → start a session in **kingsleylow123/videoediting** (environment: **videoediting**).
2. Paste a video prompt, for example:

   > Make a 10 s Reel: hook "Your ads aren't the problem. Your offer is." then 3 punchy lines and a CTA
   > "Book a free audit". Black background, yellow accent, hit sound on each line. Export and send it to me.

3. Claude builds it, renders it into `exports/`, pushes it and sends you the MP4. Save it and post.

On GitHub (phone browser): repo → `exports` → tap the video → Download → Share → Save Video.

See `CLAUDE.md` for how the studio works and `MOTION-CHEAT-CODE.md` to add the paid pack.
